# Assets

`manifest.json` is the asset list. Each building lives in `assets/buildings/<id>/` and holds the MagicaVoxel source (`.vox`), the OBJ mesh, its MTL, the 256 by 1 palette PNG, and a preview GIF.

To add an asset: copy its folder under the matching category, then add an entry to `manifest.json` with the same fields as the existing entries.
